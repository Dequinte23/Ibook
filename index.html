How to add a new book

  1. Open your GitHub repository in the browser.
  2. Create a folder called books and upload your PDF there.
  3. Create a folder called covers and upload the cover image there.
  4. Open the file books.json and add a new entry for your book.
  5. Click Commit changes. Your site updates in about 1 minute.

Template to paste inside books.json

[ { "title": "The Lion and the Jewel", "author": "Wole Soyinka", "description": "A play about tradition and change.", "cover": "covers/lion.jpg", "pdf": "books/lion.pdf" }, { "title": "Things Fall Apart", "author": "Chinua Achebe", "description": "A classic African novel.", "cover": "covers/things.jpg", "pdf": "books/things.pdf" } ]
Rules to remember:
• Separate every book with a comma , but do NOT put a comma after the last one.
• Use the exact file names you uploaded, including .pdf and .jpg.
• File names are case‑sensitive on GitHub — Lion.pdf is different from lion.pdf.
• If you do not have a cover, leave the cover line as "cover": "" and Ibook will show a coloured placeholder.
